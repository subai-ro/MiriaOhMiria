# Foundation documents

These are preserved source documents from 2026-08-07.

They carry the conceptual memory of World Zero:

- WORLD_ZERO_CANON.md: foundational handoff and canonical principles;
- WORLD_ZERO_GLOSSARY.md: shared terminology;
- WORLD_ZERO_POST_GLOSSARY_HANDOFF.md: post-glossary architecture direction;
- WORLD_ZERO_PLAYER_EXPERIENCE_NORTH_STAR.md: desired player experience;
- WORLD_ZERO_DIFFERENTIATION_IDEA_VAULT.md: exploratory ideas, not canon by
  default.

Their embedded version labels stop around D.1.3.3 and early D.1.4 planning.
Do not use those labels as current project state. Read
../../WORLD_ZERO_CURRENT_STATE.md and ../CANON_SOURCE_ORDER.md first.

The files are otherwise kept intact so later work can distinguish original
decisions from newer summaries.
